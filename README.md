# Algoritmos em Grafos

Este repositório reúne implementações em Python de conceitos e algoritmos fundamentais de teoria dos grafos, organizados por tema para estudos acadêmicos.

## Objetivo

O projeto tem como finalidade apresentar e praticar algoritmos clássicos de grafos, incluindo representação de estruturas, travessias, ordenação, conectividade, árvores geradoras, caminhos mínimos e fluxo em redes.

## Estrutura do repositório

| Pasta | Conteúdo principal |
| --- | --- |
| Introdução a Grafos | Exercícios iniciais sobre conceitos básicos de grafos |
| MatrizDeAdjacencia | Implementações utilizando matriz de adjacência |
| Lista De Adjacencia | Implementações utilizando lista de adjacência |
| Busca em Grafos | Algoritmos de busca em largura e profundidade |
| Ordenação Topológica | Implementação de ordenação topológica |
| Percurso e Conectividade | Análise de alcançabilidade e circuitos eulerianos |
| ÁrvoresGeradoras | Algoritmos de Prim, Kruskal e Borůvka |
| Caminho Minimo | Algoritmos de Bellman-Ford, Dijkstra e Floyd-Warshall |
| Fluxo em Redes | Implementação do algoritmo de Ford-Fulkerson |

## Algoritmos presentes

- Busca em largura (BFS)
- Busca em profundidade (DFS)
- Ordenação topológica
- Verificação de alcançabilidade
- Circuitos eulerianos
- Árvores geradoras mínimas
- Caminhos mínimos
- Fluxo máximo em redes

## Como executar

Pré-requisitos:
- Python 3.8 ou superior
- Nenhuma dependência externa é necessária

Exemplo de execução:

```bash
python "Lista De Adjacencia/ex1.py"
```

Ou para executar um algoritmo de busca:

```bash
python "Busca em Grafos/BFS.py"
```

## Observações

Os scripts foram desenvolvidos de forma didática, com foco no aprendizado dos conceitos e da lógica por trás dos algoritmos, sem uso de bibliotecas adicionais.
